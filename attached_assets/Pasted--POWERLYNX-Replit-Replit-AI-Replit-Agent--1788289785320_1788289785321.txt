## 1. 개발 환경 및 배포 파이프라인

Replit 작업 시작 전에 아래 환경을 명확히 인지하고 작업해 주세요.

1. **버전관리:** GitHub 레포지토리와 연동하여 작업 (Replit → GitHub 연결, 커밋/푸시 가능하도록 설정)
2. **배포:** 최종 호스팅은 **Cloudflare Pages**(또는 Cloudflare + Workers 조합)를 사용할 예정
   - **배포 방식: GitHub 레포 ↔ Cloudflare Pages 연동(Git Integration)을 기본으로 설정해 주세요.** 이렇게 연동해두면 레포에 push되는 즉시 Cloudflare가 자동으로 재배포하므로, **Replit에서 1단계 Under Construction 페이지를 만들어 push하는 것만으로도 실제 도메인에 바로 반영됩니다.** (별도로 Cursor를 거칠 필요 없음 — Cursor는 이후 세부 기능을 다듬는 편집 환경일 뿐, 배포 권한 자체는 "GitHub 레포 ↔ Cloudflare" 연동에 있음)
   - Cloudflare API 토큰이 있다면 Replit 터미널에서 `wrangler deploy`로 직접 배포도 가능(선택)
3. **후속 작업 도구:** 이 프로젝트는 Replit에서 1차 구조를 잡은 뒤, **Cursor**로 넘겨서 세부 기능(폼 연동, 관리자 기능 등 마지막 커스텀 기능)을 마무리할 계획입니다.
   - 따라서 Replit 단계에서는 **표준적이고 이식성 높은 코드 구조**로 작업해 주세요 (프레임워크 Lock-in 최소화, 정적 사이트 생성 방식 권장: Next.js(Static Export) 또는 Astro 등 Cloudflare Pages 호환 프레임워크 사용)
   - 소스코드는 GitHub 레포에 정리된 구조로 커밋 (컴포넌트/페이지/다국어 리소스 폴더 분리)
   - Replit과 Cursor 모두 같은 GitHub 레포에 push하는 방식으로 작업이 이어지므로, 어느 도구에서 작업하든 배포 파이프라인은 동일하게 유지됨
4. **환경변수/시크릿:** 이메일 폼 발송용 API 키 등은 `.env`로 분리, Cloudflare Pages 환경변수에 별도 등록 예정이므로 하드코딩 금지

## 3. 브랜드 & 디자인 가이드

### 3-1. 로고 & 컬러
- 로고: 첨부된 `POWERLYNX_2027_CATALOG_V1_0.pdf` 표지 및 각 페이지 상단의 로고(늑대/스파크 아이콘 + "POWERLYNX" 워드마크) 사용. 고해상도 로고 파일은 별도 제공 예정이니, 우선 카탈로그에서 추출한 이미지를 사용해 자리 배치
- 카탈로그 내 브랜드 컬러: 다크 차콜(#2B2B2B 계열) + 오렌지/레드 포인트 컬러(#E8552A 계열 추정) — 실제 HEX는 로고 원본 파일 수령 후 보정 예정이니 우선 이 톤으로 진행

### 3-2. 타이포그래피 / CSS — Wordshiper 디자인 시스템 그대로 적용
POWERLYNX 사이트는 wordshiper.org(Wordshiper Ministry 앱 프로젝트)에서 확정된 폰트/컬러 시스템을 그대로 가져와 적용합니다.

- **한글 폰트:** Binggrae Taom
- **영문 폰트:** EB Garamond
- **중문(간체) 폰트:** Noto Sans SC
- 언어 감지/선택에 따라 위 3개 폰트 스택을 자동 전환 (`lang` 속성 기반 CSS 폰트 스위칭)
- 다국어 24개국 지원 시, 위 3개 언어군에 속하지 않는 언어(예: 아랍어, 태국어, 베트남어 등)는 각 언어의 표준 웹폰트(Noto Sans 계열)로 폴백 처리
- **주의:** POWERLYNX의 포인트 컬러(§3-1)는 유지하되, 타이포그래피 스케일/줄간격/헤딩 웨이트 등 CSS 토큰 구조는 Wordshiper 시스템의 방식을 그대로 이식
- (Cursor 단계에서 실제 wordshiper.org의 CSS 변수 파일을 그대로 import 또는 복사하여 연결할 예정이므로, Replit 단계에서는 **CSS 변수(디자인 토큰) 구조로 폰트/컬러를 관리**해 나중에 손쉽게 교체 가능하도록 설계해 주세요)

### 3-3. 반응형 기준
- 모바일 (~480px), 태블릿 (~768px), 데스크톱 (1200px+) 3단 브레이크포인트 기본
- 상단 내비게이션은 모바일에서 햄버거 메뉴로 전환
- 제품 그리드는 모바일 1열 → 태블릿 2열 → 데스크톱 3~4열
